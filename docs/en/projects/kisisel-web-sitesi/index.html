Website · 2026

Personal Website

Source code (GitHub)

The site you are looking at. Instead of an off-the-shelf site builder, it is generated by a small Python program that turns Markdown files into HTML pages, and it is published on GitHub Pages.

Highlights

  • Two languages: Turkish and English; every page links to its counterpart in the other language.
  • Accessibility: The Atkinson Hyperlegible typeface, designed for legibility, high colour contrast, keyboard navigation and a “skip to content” link. The background animation stops for visitors who prefer reduced motion.
  • Speed: No framework; pages are generated ahead of time as plain HTML. Google Lighthouse scores 100 in performance, accessibility, best practices and SEO.
  • Search engines: Sitemap, canonical links, Open Graph previews and schema.org data.
  • Responsive design and a downloadable CV.

Built with

Python, Jinja2, Markdown, HTML, CSS, JavaScript, GitHub Pages.
